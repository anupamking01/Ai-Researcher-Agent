# Automated–human reconciliation output verification

This note defines the publication-integrity boundary for the frozen descriptive reconciliation. A future successful reconciliation should publish canonical JSON, a deterministic Markdown rendering, and a manifest binding exact output bytes, verified upstream input fingerprints, and the reconciler/readiness implementation. Verification must recompute from the already-verified automated and human analysis artifacts, preserve missing human pairs without imputation, add no hypothesis test, and rerun no treatment or common evaluator.

This mechanism does not create a human-evaluation result. Real blinded annotations, pre-unblinding agreement, frozen human analysis, and descriptive reconciliation remain pending scientific gates.
